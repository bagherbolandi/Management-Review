# Management-Review

فایل و راهنمای بازنگری مدیریت سیستم‌های مدیریت یکپارچه (IMS) برای شرکت‌های تولیدی قطعات خودرو و مواد کامپوزیتی.

## خروجی اصلی

| فایل | توضیح |
|---|---|
| `IMS_Management_Review_FA_v1.xlsx` | فرم و صورت‌جلسه بازنگری مدیریت، مطابق بند 9.3 استانداردهای ISO 9001:2026 · ISO 14001:2026 · ISO 45001:2018 و الزامات تکمیلی IATF 16949:2016 |
| `docs/راهنمای_بازنگری_مدیریت.md` | مبنای الزامات، جدول بندها، مدل ردیابی، گام‌های استفاده و منابع بررسی‌شده |
| `tools/build_management_review.py` | اسکریپت بازتولید فایل اکسل (openpyxl) |

## ساختار فایل اکسل

1. `1-جلسه و تنظیمات` – اطلاعات جلسه، حاضرین، نسخه معتبر استانداردها و کنترل تکمیل خودکار
2. `2-ورودی‌ها` – جدول یکپارچه ۲۹ ورودی الزامی (مشترک + اختصاصی IATF/EMS/OHS)
3. `3-خروجی و مصوبات` – ۹ خروجی الزامی، تصمیم، مسئول، منابع، مهلت، وضعیت و اثربخشی
4. `4-پایش و اثربخشی` – نوبت‌های پایش، شاهد اجرا، معیار و نتیجه اثربخشی
5. `5-صورتجلسه` – خلاصه مدیریتی و صورت‌جلسه قابل چاپ برای جلسه و ممیز

## بازتولید فایل

```bash
pip install openpyxl
python3 tools/build_management_review.py
```

> توجه: متن کامل استانداردها در اختیار نبوده و بندها بر پایه خلاصه‌های منتشرشده و متن Sanctioned Interpretations تنظیم شده‌اند؛ پیش از استفاده در ممیزی، شماره بندها با نسخه خریداری‌شده سازمان تطبیق داده شود.
