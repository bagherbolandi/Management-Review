# Management-Review

فایل و راهنمای بازنگری مدیریت سیستم‌های مدیریت یکپارچه (IMS) برای شرکت‌های تولیدی قطعات خودرو و مواد کامپوزیتی.

مبنای طراحی: بند 9.3 استانداردهای **ISO 9001:2026** و **ISO 14001:2026**، بند 9.3 **ISO 45001:2018** و بندهای 9.3.1.1 / 9.3.2.1 / 9.3.3.1 **IATF 16949:2016**.

## فایل‌های تحویلی

| فایل | توضیح |
|---|---|
| `IMS_Management_Review_FA_v1.xlsx` | فرم خالی و آماده استفاده: ۶ برگه فارسی راست‌به‌چپ |
| `IMS_Management_Review_FA_v1_Demo.xlsx` | نسخه نمایشی پرشده (۲۹ ورودی، ۲۶ مصوبه، ۱۷ رکورد پایش) با داده غیرواقعی و رنگ‌بندی مشخص |
| `docs/راهنمای_بازنگری_مدیریت.md` | مبنای الزامات، جدول بندها، مدل ردیابی، قواعد تکمیل و منابع |
| `tools/build_management_review.py` | اسکریپت بازتولید فرم |
| `tools/fill_demo_data.py` | اسکریپت تولید نسخه نمایشی |
| `tools/verify_workbook.py` | آزمون ساختار و ارزیابی همه فرمول‌ها |

## ساختار فایل اکسل

| برگه | محتوا |
|---|---|
| `0-راهنما` | ۹ گام اجرا · مالک داده هر ۲۹ ورودی · ۱۰ قاعده تکمیل |
| `1-جلسه و تنظیمات` | اطلاعات جلسه و دوره · حاضرین · نسخه و مهلت انتقال استانداردها · ۱۳ شاخص کنترل خودکار |
| `2-ورودی‌ها` | جدول یکپارچه ۲۹ ورودی الزامی با موضوع، اطلاعات موردنیاز، نتیجه بررسی، مستندات و بند استاندارد |
| `3-خروجی و مصوبات` | ۹ خروجی الزامی + ۱۱ موضوع تصمیم تکمیلی + ردیف آزاد؛ تصمیم، مسئول، منابع، مهلت، وضعیت، نتیجه و اثربخشی |
| `4-پایش و اثربخشی` | نوبت‌های پایش، درصد پیشرفت، شاهد، معیار و نتیجه اثربخشی، روز تا مهلت |
| `5-صورتجلسه` | صورت‌جلسه قابل چاپ: خلاصه وضعیت، ۲۹ ورودی، نتیجه‌گیری، ۲۵ مصوبه، امضا و توزیع |

## بازتولید و آزمون

```bash
pip install openpyxl
python3 tools/build_management_review.py
python3 tools/fill_demo_data.py
python3 tools/verify_workbook.py --calc
```

> توجه: متن کامل استانداردها در اختیار نبوده و بندها بر پایه خلاصه‌های منتشرشده و متن Sanctioned Interpretations تنظیم شده‌اند؛ پیش از استفاده در ممیزی، شماره بندها با نسخه خریداری‌شده سازمان تطبیق داده شود.
